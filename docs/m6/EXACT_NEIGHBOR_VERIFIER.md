# Exact macOS neighbor identity observation

`MacNeighborIdentityVerifier` supplies the read-only neighbor-MAC adapter for `HelperPreMutationGate`. The production instance uses the existing typed `systemNetworkCommandRunner()` to execute `/usr/sbin/arp -i <selected-interface> -n <exact-ipv4>` with a 1500 ms deadline and 4096-byte combined output cap. Inputs are validated before command invocation. The verifier accepts only a completed, exit-zero, stderr-free query with one short ASCII line that names the exact requested IP, selected interface, and a resolved six-octet unicast MAC. It normalizes one- or two-digit hex octets to lowercase two-digit form. Missing, ambiguous, malformed, over-limit, mismatched, multicast, and all-zero observations return no identity.

This is a local neighbor-table observation with unknown cache-entry age; it does not refresh ARP. It does not prove that the remote device owns the MAC, that packets reach it, or that the entry remains unchanged after the query. The pre-mutation gate separately requires matching direct-route evidence and probes the listener last. No ARP packet is sent or modified by this verifier. Live helper wiring and authorization remain open.
